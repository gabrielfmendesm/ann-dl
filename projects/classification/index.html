    Classification — Stroke Prediction

    Gabriel Fernando Missaka Mendes · Eduardo Takei Yaginuma · Luca Santana Feltrin — Insper, Artificial Neural Networks and Deep Learning, 2026.2

    This report trains a neural network on the dataset of our EDA — same task, same split, same preprocessing pipeline — and asks the two questions of this delivery: does the network learn something simpler models do not, and how far can the number it reports be trusted? The short answers: on the test set it matches logistic regression rather than beating it, and its test average precision, measured on 50 strokes, is uncertain to within about ±0.1.

    Approach. The code is split into files under code/: common.py (the settings fixed in step 0, the EDA's data and pipeline, the validation folds and the report helpers), starting_point.py (step 0), baselines.py (step 1), network.py (the network and its training loop), validation.py (the cross-validation shared by every model), search.py (steps 2–4), evaluate.py (step 5), errors.py (step 6), main.py, which runs the steps in order, and check_report.py, which confirms that every table, every figure, the key numbers of the text and every row of the results summary are exactly what the scripts produced. Every table, number and figure in this report is reproduced by installing requirements.txt and running, from the repository root:

    python docs/projects/classification/code/main.py
python docs/projects/classification/code/check_report.py

    The run takes about four minutes on a laptop CPU. It writes Figures 1–7 to figures/ and, under results/, every table as tableNN.csv (NN is the table's number in this report) and in Markdown, and the numbers quoted in the text as JSON. The data, the split and the pipeline come from the EDA's code/preprocessing.py, unchanged except that step 0 removes the pipeline's BMI-missing indicator, and the split is checked row by row against the one the EDA saved. The results were produced with torch 2.15.0 and scikit-learn 1.9.0 on an Apple M2 Max CPU, where repeated runs give identical numbers; a clean clone in a fresh virtual environment reproduces every table and number byte for byte.

    Seeds. SEED = 42, the EDA's constant, fixes the split, the validation folds and gradient boosting (random_state=42). Every network calls torch.manual_seed(seed) before it is built, which fixes its initial weights and its dropout masks, and draws its mini-batches with a torch.Generator of the same seed: 42 throughout validation, 42 to 46 for the five final retrainings of step 5. The bootstrap and the permutations use np.random.default_rng(42); logistic regression has no randomness.

    Rule followed throughout. Steps 0 to 4 use only the 4,088 training rows: every choice — the pipeline, the configuration, the number of epochs, each model's decision threshold — is made on 5 validation folds carved out of them, with the pipeline refitted inside every fold. The 1,022 test rows are read once, in step 5, after all of that was fixed; step 6 analyses the seed-42 network on those same test rows and changes nothing. Only steps 5 and 6 (evaluate.py and errors.py) receive the test rows. The scripts were run several times while this report was written; none of the choices above changed after the test set was first read, and every run gives the same numbers.

    Challenges.

    • Few positives. The training set holds 199 strokes, so each validation fold holds 39 or 40, and the validation AP of every learned model has a fold-to-fold standard deviation of 0.02 to 0.06. The report gives each one as a mean with its standard deviation and chooses among configurations with the one-standard-error rule rather than the highest mean.
    • A feature that may describe the label. The EDA found BMI missing about five times more often among the strokes, without knowing whether BMI is recorded before the event. Its plan said to prefer the model without the missingness indicator if the indicator carried the gain. The gain it shows is smaller than the fold-to-fold standard deviation, but nothing says when BMI is recorded, so step 0 takes the conservative reading and removes it, for every model.
    • A weighted loss and a threshold. Weighting the positives in the loss distorts the probabilities, so the decision threshold is chosen on validation from the cost of the errors fixed in step 0, not read off as 0.5.
    • A test set with 50 strokes. One test number says little on its own: step 5 adds five retrainings with different seeds and a paired bootstrap of the test rows.
    code/main.py
    """Reproduce every table, number and figure of the classification report.

Usage, from the repository root:
    python docs/projects/classification/code/main.py

The steps run in the order of the report. Steps 0 to 4 use only the training rows and their validation folds.
Steps 5 and 6 are the only ones that receive the test rows: step 5 evaluates every model on them once, step 6
analyses the errors of the seed-42 network on those same rows and changes no choice.
Writes Figures 1-7 to figures/ and the tables (Markdown and CSV) and numbers (JSON) to results/.
"""

import json

import baselines
import errors
import evaluate
import search
import starting_point
from common import RESULTS_DIR, folds, load_data
from validation import fold_matrices


def main():
    X_train, X_test, y_train, y_test = load_data()
    cv_folds = folds(y_train)

    make_preprocessor = starting_point.run(X_train, y_train, cv_folds)                       # step 0
    n_inputs = make_preprocessor().fit_transform(X_train).shape[1]
    mats = fold_matrices(X_train, y_train, cv_folds, make_preprocessor)
    oof_baselines, best_baseline = baselines.run(mats, y_train)                               # step 1
    chosen = search.run(X_train, y_train, cv_folds, make_preprocessor, mats, n_inputs)        # steps 2-4
    final = evaluate.run(X_train, X_test, y_train, y_test, make_preprocessor, chosen,          # step 5
                         oof_baselines, best_baseline)
    errors.run(X_test, y_test, final)                                                        # step 6
    (RESULTS_DIR / "split_sizes.json").write_text(json.dumps({
        "train": len(y_train), "train_positives": int(y_train.sum()), "test": len(y_test),
        "test_positives": int(y_test.sum()), "validation_folds": [len(v) for _, v in cv_folds],
        "validation_positives": [int(y_train[v].sum()) for _, v in cv_folds]}, indent=2) + "\n")


if __name__ == "__main__":
    main()

    0. Starting point

    Main metric and success criterion, fixed before any model was trained (constants MAIN_METRIC, CRITERION_GAIN and COST_MISS in code/common.py). The three points below were committed word for word in 66f89ca, before the first training run:

    • Main metric: average precision (AP, the area under the precision–recall curve). Only 4.87% of the rows are positive, so accuracy rewards a model that never predicts a stroke, and ROC-AUC hides false alarms behind the large number of true negatives; AP is read against the 4.87% that a random ranking scores.
    • Success criterion: the network's mean test AP over 5 seeds is at least 15% higher than the test AP of the best baseline (the baseline with the highest validation AP), and the gap is larger than the network's standard deviation across the 5 seeds.
    • Cost of the errors, for the decision threshold: a missed stroke costs as much as 20 false alarms. A false alarm sends a patient to a follow-up consultation; a missed stroke withholds preventive care from someone who will have one.

    The pipeline. load_raw(), split() and build_preprocessor() are imported from the EDA's code/preprocessing.py: the same stratified 80/20 split with random_state=42 (4,088 training rows with 199 strokes, 1,022 test rows with 50) and the same ColumnTransformer — median imputation, log1p and standardization for glucose and BMI, standardization for age, full one-hot encoding of the seven categorical features. It is never fitted on more than the rows a model trains on: inside each validation fold on that fold's training part, and for the final models on the 4,088 training rows. The validation folds are StratifiedKFold(n_splits=5, shuffle=True, random_state=42) on the training rows, as the EDA planned: 817 or 818 rows each, with 39 or 40 strokes.

    The EDA's grading and its own plan. The EDA has not been graded yet, so there are no grading corrections to apply. Its synthesis (section 5) listed what this delivery should do, and this report follows that list — all but the optional glucose second-mode flag, which step 6 uses as a subgroup rather than as a feature: average precision next to the prevalence; the threshold chosen on validation; pos_weight ≈ 19.5 computed inside the training folds; cross-validation with the pipeline refitted in each fold; recall per age band (step 6, through its complement, the miss rate); the sensitivity check on the two adult BMIs below 12 (step 4); and the BMI-missing indicator trained with and without, below.

    Table 1 — Validation AP with and without the BMI-missing indicator (5 folds: mean and sample sd). The network is the one of step 2.

    model AP with the indicator sd (with) AP without it sd (without) gain from the indicator
    Logistic regression 0.2200 0.0434 0.1891 0.0410 0.0308
    Gradient boosting 0.1948 0.0317 0.1966 0.0441 −0.0017
    Network (step 2) 0.2180 0.0578 0.1933 0.0465 0.0247

    The indicator raises the mean validation AP of logistic regression by 0.0308 and of the network by 0.0247; gradient boosting does not gain from it (−0.0017). Both gains are smaller than the fold-to-fold standard deviations (0.0410 to 0.0578). The EDA's rule was: If the indicator carries the gain, treat it as a collection artifact and prefer the model without it, unless BMI is known to be recorded before the prediction. Nothing in the dataset says when BMI is recorded, so we take the conservative reading: any gain makes the indicator suspect. The network, the model this delivery is about, gains from it (and so does logistic regression), so the indicator is removed, for every model, to keep the comparison between them on one pipeline (missing="drop" in the ColumnTransformer; the rest of the EDA's pipeline is untouched). Logistic regression and the network give up some validation AP for not relying on a feature that may only describe how the stroke patients were recorded. The removal also decides which baseline is best on validation: with the indicator it would have been logistic regression (0.2200), without it gradient boosting (Table 2), the baseline the criterion of step 0 is measured against. The pipeline now outputs 23 columns; in fold 1 it outputs 22, because the training set's only gender = Other row falls in that fold's validation part, so its encoder never sees that category.

def load_data():
    """The EDA's split, checked row by row against the one the EDA saved in results/split.csv."""
    X_train, X_test, y_train, y_test = split(load_raw())
    saved = pd.read_csv(EDA_SPLIT)
    for name, part in (("train", X_train), ("test", X_test)):
        if list(part.index) != saved.loc[saved["partition"] == name, "row"].tolist():
            raise ValueError(f"the {name} rows differ from the EDA's split")
    return X_train, X_test, y_train.to_numpy(), y_test.to_numpy()


def folds(y_train):
    """The validation folds every model uses: N_FOLDS stratified, shuffled folds of the training rows."""
    splitter = StratifiedKFold(n_splits=N_FOLDS, shuffle=True, random_state=SEED)
    return list(splitter.split(np.zeros(len(y_train)), y_train))

def md_table(df, floatfmt=None):
    """Render a DataFrame as a Markdown table; floatfmt maps a column to its format spec (default .4f).

    Integers get a thousands separator, negative numbers a true minus sign, as in the prose, and a missing value
    a dash.
    """
    floatfmt = floatfmt or {}
    header = "| " + " | ".join(str(c) for c in df.columns) + " |"
    rule = "|" + "|".join("---" for _ in df.columns) + "|"
    rows = []
    for values in df.astype(object).itertuples(index=False):   # object dtype keeps each cell's own type
        cells = []
        for c, v in zip(df.columns, values):
            if isinstance(v, (float, np.floating)) and np.isnan(v):
                text = "—"
            elif isinstance(v, (float, np.floating)):
                text = format(v, floatfmt.get(c, ".4f"))
            elif isinstance(v, (int, np.integer)) and not isinstance(v, (bool, np.bool_)):
                text = f"{v:,}"
            else:
                text = str(v)
            if isinstance(v, (int, float, np.number)) and text.startswith("-"):
                text = "−" + text[1:]
            cells.append(text)
        rows.append("| " + " | ".join(cells) + " |")
    return "\n".join([header, rule, *rows])


class Results:
    """Collects the numbered tables and the numbers one step of the report quotes, then writes them to results/.

    Each table goes to results/table{NN}.csv and, rendered in Markdown, to results/{name}_tables.md; the numbers

    code/starting_point.py
    """Step 0 — the starting point: the EDA's pipeline, and the check its synthesis asked for (Table 1).

The EDA found BMI missing about five times more often among the positives and could not tell whether BMI is
recorded before the event the label describes. Its plan: train with and without the BMI-missing indicator, and if
the indicator carries a gain, treat it as a collection artifact and prefer the model without it. This step runs
that check on the validation folds and returns the pipeline every later step uses, for every model alike.
"""

from functools import partial

import pandas as pd

from baselines import make_baselines
from common import N_FOLDS, Results, build_preprocessor
from search import DEFAULT
from validation import cv_network, cv_sklearn, fold_matrices, mean_sd, without_indicator


def run(X_train, y_train, folds):
    """Table 1: the learned baselines and the network of step 2 with and without the indicator. Returns the factory
    of the pipeline every later step uses."""
    results = Results("starting_point")
    pipelines = {"with": build_preprocessor, "without": without_indicator}
    mats = {k: fold_matrices(X_train, y_train, folds, make) for k, make in pipelines.items()}
    widths = {k: [fold.X_train.shape[1] for fold in v] for k, v in mats.items()}

    cross_validate = {name: partial(cv_sklearn, model) for name, model in make_baselines().items()
                      if name != "Majority class"}
    cross_validate["Network (step 2)"] = partial(cv_network, DEFAULT)
    rows = []
    for name, cv in cross_validate.items():
        ap = {k: cv(m)["ap"] for k, m in mats.items()}
        (with_mean, with_sd), (without_mean, without_sd) = mean_sd(ap["with"]), mean_sd(ap["without"])
        rows.append({"model": name, "AP with the indicator": with_mean, "sd (with)": with_sd,
                     "AP without it": without_mean, "sd (without)": without_sd,
                     "gain from the indicator": with_mean - without_mean})
    table = pd.DataFrame(rows)
    results.table(1, f"Validation AP with and without the BMI-missing indicator ({N_FOLDS} folds: mean and sample "
                     "sd)", table)

    gain = table.set_index("model")["gain from the indicator"]
    drop = bool(gain["Network (step 2)"] > 0)   # the EDA's rule: a gain means the indicator is suspect
    results.metrics.update({"gain": gain.to_dict(), "drop_indicator": drop, "input_widths": widths})
    results.write()
    print(table.to_string(index=False))
    print(f"drop the BMI-missing indicator: {drop}; inputs per fold {widths}")
    return without_indicator if drop else build_preprocessor

    1. Baselines

    The three baselines are fitted on the same fold matrices as the network: the trivial DummyClassifier(strategy="most_frequent"), the linear LogisticRegression(class_weight="balanced") and, as the optional one, HistGradientBoostingClassifier(class_weight="balanced"). The two learned ones weight the classes as the network's pos_weight does.

    Table 2 — The baselines on the 5 validation folds (mean and sample standard deviation across folds).

    model AP (mean) AP (sd) ROC-AUC (mean) ROC-AUC (sd)
    Majority class 0.0487 0.0005 0.5000 0.0000
    Logistic regression 0.1891 0.0410 0.8381 0.0120
    Gradient boosting 0.1966 0.0441 0.8267 0.0195
    • The trivial baseline scores the prevalence. It gives every patient the same score, so its AP is the share of strokes, 0.0487, and its ROC-AUC is 0.5: this is the floor any model must clear.
    • Both learned baselines reach about four times the floor: logistic regression 0.1891 and gradient boosting 0.1966. Their ROC-AUCs, 0.8381 and 0.8267, are close to the 0.834 that age alone reaches in the EDA (Table 10 of the EDA), which suggests that most of their ranking comes from age (step 6 confirms it for the network).
    • Gradient boosting is the best baseline on validation, the one the criterion of step 0 refers to. It leads logistic regression by 0.0075, less than a fifth of either model's fold-to-fold standard deviation (0.0410 and 0.0441), so the two are tied in practice.

    Code

    code/validation.py
    """Cross-validation on the training rows, shared by every model: the network and the baselines see exactly the same
fold matrices, built by a pipeline fitted on each fold's training part only."""

from typing import NamedTuple

import numpy as np
from sklearn.metrics import average_precision_score, roc_auc_score

from common import SEED, build_preprocessor
from network import predict_proba, train


class Fold(NamedTuple):
    """One validation fold: the pipeline's output on the fold's training and validation parts, their labels, and the
    positions of the validation rows among the training rows."""
    X_train: np.ndarray
    y_train: np.ndarray
    X_val: np.ndarray
    y_val: np.ndarray
    val_idx: np.ndarray


def without_indicator():
    """The EDA's pipeline without its BMI-missing indicator."""
    preprocessor = build_preprocessor()
    preprocessor.set_params(missing="drop")
    return preprocessor


def fold_matrices(X_train, y_train, folds, make_preprocessor, prepare=None):
    """One Fold per validation fold. The pipeline is fitted on the fold's training part and only applied to its
    validation part. `prepare` optionally edits the raw rows first (the BMI sensitivity check)."""
    X = prepare(X_train) if prepare else X_train
    mats = []
    for train_idx, val_idx in folds:
        preprocessor = make_preprocessor()
        mats.append(Fold(preprocessor.fit_transform(X.iloc[train_idx]), y_train[train_idx],
                         preprocessor.transform(X.iloc[val_idx]), y_train[val_idx], val_idx))
    return mats


def scores(y, p):
    """Average precision and ROC-AUC of the probabilities p for the labels y."""
    return average_precision_score(y, p), roc_auc_score(y, p)


def cv_sklearn(model, mats):
    """A scikit-learn baseline refitted on every fold; validation AP and ROC-AUC per fold and the out-of-fold
    probabilities (each training row predicted by the model that did not see it)."""
    out = {"ap": [], "auc": [], "oof": np.zeros(sum(len(fold.val_idx) for fold in mats))}
    for fold in mats:
        p = model.fit(fold.X_train, fold.y_train).predict_proba(fold.X_val)[:, 1]
        out["oof"][fold.val_idx] = p
        ap, auc = scores(fold.y_val, p)
        out["ap"].append(ap)
        out["auc"].append(auc)
    return out


def cv_network(config, mats, seed=SEED):
    """One network per fold, early-stopped on the fold's validation part with its best weights restored; the same
    outputs as cv_sklearn, plus the best epochs and the curves."""
    out = {"ap": [], "auc": [], "oof": np.zeros(sum(len(fold.val_idx) for fold in mats)), "best_epoch": [],
           "histories": []}
    for fold in mats:
        model, history, best_epoch = train(fold.X_train, fold.y_train, config, seed, X_val=fold.X_val,
                                           y_val=fold.y_val)
        p = predict_proba(model, fold.X_val)
        out["oof"][fold.val_idx] = p
        ap, auc = scores(fold.y_val, p)
        out["ap"].append(ap)
        out["auc"].append(auc)
        out["best_epoch"].append(best_epoch)
        out["histories"].append(history)
    return out


def mean_sd(values):
    """Mean and sample standard deviation (ddof = 1) across folds or seeds."""
    return float(np.mean(values)), float(np.std(values, ddof=1))
    code/baselines.py
    """Step 1 — the baselines, on the same pipeline and the same validation folds as the network (Table 2)."""

import pandas as pd
from sklearn.dummy import DummyClassifier
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.linear_model import LogisticRegression

from common import N_FOLDS, SEED, Results
from validation import cv_sklearn, mean_sd


def make_baselines():
    """The trivial and the linear baseline the statement requires, and gradient boosting as the optional one.
    The two learned ones weight the classes as the network's pos_weight does."""
    return {
        "Majority class": DummyClassifier(strategy="most_frequent"),
        "Logistic regression": LogisticRegression(class_weight="balanced", max_iter=1000),
        "Gradient boosting": HistGradientBoostingClassifier(class_weight="balanced", random_state=SEED),
    }


def run(mats, y_train):
    """Cross-validate every baseline; returns the out-of-fold probabilities and the best baseline (highest mean AP)."""
    results = Results("baselines")
    rows, oof = [], {}
    for name, model in make_baselines().items():
        cv = cv_sklearn(model, mats)
        oof[name] = cv["oof"]
        (ap, ap_sd), (auc, auc_sd) = mean_sd(cv["ap"]), mean_sd(cv["auc"])
        rows.append({"model": name, "AP (mean)": ap, "AP (sd)": ap_sd, "ROC-AUC (mean)": auc, "ROC-AUC (sd)": auc_sd})
        results.metrics[name] = {"ap_folds": cv["ap"], "auc_folds": cv["auc"]}
    table = pd.DataFrame(rows)
    best = table.loc[table["AP (mean)"].idxmax(), "model"]
    results.metrics.update({"best_baseline": best, "prevalence_train": float(y_train.mean()),
                            "positives_per_fold": [int(fold.y_val.sum()) for fold in mats]})
    results.table(2, f"The baselines on the {N_FOLDS} validation folds (mean and sample standard deviation across "
                     "folds)", table)
    results.write()
    print(table.to_string(index=False))
    print(f"best baseline on validation: {best}")
    return oof, best

    output 16 → 1 none (logit) Glorot (Xavier) normal 17
    • Input and output. 23 inputs, the columns of the pipeline, and one output unit that returns a logit. The loss is BCEWithLogitsLoss, which applies the sigmoid itself in a numerically stable form; the model's probability of a stroke, the sigmoid of the logit, is computed only to make predictions (it is not a calibrated risk: see the limitations in step 7). pos_weight is the ratio of negatives to positives in the rows the network trains on (19.44 to 19.57 across the folds, 19.54 on the full training set), so the strokes, as a group, weigh as much in the loss as the non-strokes (199 against 3,889 in the full training set).
    • Layers and widths. Two hidden layers of 32 and 16 units, enough to combine features (age with hypertension, glucose with age) that a linear model can only add. They give 1,313 parameters for 4,088 training rows (3,270 or 3,271 in each fold): fewer parameters than rows, but many more than the 199 positives that carry the signal, which is why steps 3 and 4 watch for overfitting. The widths are a starting point, not a tuned choice: 32 units, slightly more than the 23 inputs, let the first layer form combinations without compressing them first, 16 halve that on the way to the single output, and step 4 tries a narrower network (16) and a wider one (64-32) around it.
    • Activation and initialization. ReLU after each hidden layer. Hidden weights start from He (Kaiming) normal, the variance that keeps ReLU activations from shrinking or growing from layer to layer; the output layer, which has no ReLU after it, from Glorot (Xavier) normal. Biases start at 0: with pos_weight the two classes weigh the same, so a logit near 0 — even odds — is the right place to start, and the random output weights only scatter the first logits around it.

    """The network of this deliverable: an MLP in PyTorch that returns one logit, and its training loop.

The training loop follows the statement's skeleton: one optimizer step per mini-batch, the validation loss after
every epoch, early stopping with a patience, and the best weights restored at the end (kept in memory rather
than in a file).
"""

import copy

import numpy as np
import torch
from sklearn.metrics import average_precision_score
from torch import nn
from torch.utils.data import DataLoader, TensorDataset

BATCH_SIZE = 128     # about 6 positives per batch at the 4.87% rate; a batch without any is rare (0.17%)
MAX_EPOCHS = 300     # an upper bound; early stopping decides
PATIENCE = 30        # epochs without a lower validation loss before stopping


class MLP(nn.Module):
    """n_inputs -> hidden[0] -> ... -> hidden[-1] -> 1 logit, ReLU after every hidden layer and optional dropout
    after every ReLU. Hidden layers use He (Kaiming) normal initialization, the variance that keeps ReLU
    activations from shrinking or growing layer after layer; the output layer, which has no ReLU after it, uses
    Glorot (Xavier) normal. Every bias starts at 0."""

    def __init__(self, n_inputs, hidden, dropout=0.0):
        super().__init__()
        layers, width = [], n_inputs
        for units in hidden:
            linear = nn.Linear(width, units)
            nn.init.kaiming_normal_(linear.weight, nonlinearity="relu")
            nn.init.zeros_(linear.bias)
            layers += [linear, nn.ReLU()]
            if dropout > 0:
                layers.append(nn.Dropout(dropout))
            width = units
        output = nn.Linear(width, 1)
        nn.init.xavier_normal_(output.weight)
        nn.init.zeros_(output.bias)
        layers.append(output)
        self.layers = nn.Sequential(*layers)

    def forward(self, x):
        """The logit of a stroke, one per row: the loss applies the sigmoid itself."""
        return self.layers(x).squeeze(-1)

    def n_parameters(self):
        """The number of trainable weights and biases."""
        return sum(p.numel() for p in self.parameters())


def to_tensor(a):
    """A float32 tensor, the dtype of the network's weights."""
    return torch.as_tensor(np.asarray(a, dtype=np.float32))


def predict_proba(model, X):
    """Probability of a stroke for each row of X (the sigmoid of the logit), with dropout switched off."""
    model.eval()
    with torch.no_grad():
        return torch.sigmoid(model(to_tensor(X))).numpy()


def train(X_train, y_train, config, seed, X_val=None, y_val=None, epochs=None):
    """Train one network. Returns (model, history, best_epoch).

    config: hidden (list of widths), dropout, lr, weight_decay. AdamW is used throughout; with weight_decay 0 it is
    exactly Adam. The decay applies to the weight matrices only: biases shift the activations rather than scale them,
    so they are left out, as the course recommends. The loss is BCEWithLogitsLoss with pos_weight = negatives /
    positives of y_train, so the few positives weigh as much in the gradient as all the negatives.

    With a validation set: up to MAX_EPOCHS epochs, early stopping on the validation loss with PATIENCE, and the
    weights of the best epoch restored. Without one (the final retraining): exactly `epochs` epochs.
    Both losses in the history are measured after each epoch with dropout off, so they are comparable.
    """
    if X_val is None and not epochs:
        raise ValueError("without a validation set to stop on, the number of epochs must be given")
    torch.manual_seed(seed)   # the initial weights and the dropout masks
    model = MLP(X_train.shape[1], config["hidden"], config["dropout"])
    y_train = np.asarray(y_train)
    pos_weight = torch.tensor((y_train == 0).sum() / (y_train == 1).sum(), dtype=torch.float32)
    loss_fn = nn.BCEWithLogitsLoss(pos_weight=pos_weight)
    weights = [p for name, p in model.named_parameters() if name.endswith("weight")]
    biases = [p for name, p in model.named_parameters() if name.endswith("bias")]
    optimizer = torch.optim.AdamW([{"params": weights, "weight_decay": config["weight_decay"]},
                                   {"params": biases, "weight_decay": 0.0}], lr=config["lr"])
    Xt, yt = to_tensor(X_train), to_tensor(y_train)
    loader = DataLoader(TensorDataset(Xt, yt), batch_size=BATCH_SIZE, shuffle=True,
                        generator=torch.Generator().manual_seed(seed))   # the order of the mini-batches
    if X_val is not None:
        Xv, yv = to_tensor(X_val), to_tensor(y_val)

    history = {"train_loss": [], "val_loss": [], "val_ap": []}
    best_loss, best_state, best_epoch, wait = float("inf"), None, 0, 0
    for epoch in range(1, (epochs or MAX_EPOCHS) + 1):
        model.train()
        for xb, yb in loader:
            optimizer.zero_grad()
            loss = loss_fn(model(xb), yb)
            loss.backward()
            optimizer.step()

        model.eval()
        with torch.no_grad():
            history["train_loss"].append(loss_fn(model(Xt), yt).item())
            if X_val is None:
                continue
            val_logits = model(Xv)
            val_loss = loss_fn(val_logits, yv).item()
        history["val_loss"].append(val_loss)
        history["val_ap"].append(average_precision_score(y_val, val_logits.numpy()))
        if val_loss < best_loss:
            best_loss, best_epoch, wait = val_loss, epoch, 0
            best_state = copy.deepcopy(model.state_dict())   # keep the best weights
        else:
            wait += 1
            if wait == PATIENCE:
                break
    if X_val is not None:
        model.load_state_dict(best_state)
    else:
        best_epoch = epochs
    return model, history, best_epoch

    3. Training

    • Optimizer: AdamW with weight decay 0 for the network of step 2 — exactly Adam, the course's default for an MLP on tabular data; the weight decay is a hyperparameter of step 4. Adam adapts the step size of each parameter, which suits inputs as different as standardized ages and one-hot flags.
    • Learning rate 10⁻³, the course's starting point for Adam; step 4 also tries 3 × 10⁻³.
    • Batches of 128 rows: at a 4.87% prevalence a batch holds about 6 strokes on average, and a batch with none at all comes up with probability about 0.17%, so the positive term of the loss is present in almost every step.
    • Up to 300 epochs with early stopping on the validation loss: after each epoch the weighted loss is computed on the fold's validation part, the weights of the lowest validation loss are kept in memory, training stops after 30 epochs without improvement, and the best weights are restored. The patience is long because the validation loss of a fold with 39 or 40 strokes moves from epoch to epoch (Figure 1): a short one would stop on a random bump, while 30 more epochs cost a fraction of a second each and the restored weights make them harmless. The network of step 2 stops between epochs 40 and 48, far below the cap of 300. The training and validation losses are both measured after each epoch with dropout off, so the two curves are comparable.

def run(X_train, y_train, folds, make_preprocessor, mats, n_inputs):
    """Steps 2 to 4 on the fold matrices `mats` (Tables 3-7, Figures 1-2). Returns the chosen configuration, its
    out-of-fold probabilities and the number of epochs of the final retraining."""
    results = Results("search")

    # --- Step 2: the network ---------------------------------------------------------------------
    results.table(3, f"The network of step 2, layer by layer ({n_inputs} inputs)",
                  architecture_table(DEFAULT, n_inputs))
    n_params = MLP(n_inputs, DEFAULT["hidden"]).n_parameters()
    results.metrics.update({
        "n_inputs": n_inputs, "fold_inputs": [fold.X_train.shape[1] for fold in mats], "default_params": n_params,
        "train_rows": len(y_train), "fold_train_rows": [len(fold.y_train) for fold in mats], "batch_size": BATCH_SIZE,
        "max_epochs": MAX_EPOCHS, "patience": PATIENCE,
        "pos_weight_folds": [float((fold.y_train == 0).sum() / fold.y_train.sum()) for fold in mats],
    })

    # --- Step 3: the network trained with early stopping -----------------------------------------
    default_cv = cv_network(DEFAULT, mats)
    rows = []
    for k, history in enumerate(default_cv["histories"]):
        best = default_cv["best_epoch"][k]
        rows.append({"fold": k + 1, "validation positives": int(mats[k].y_val.sum()),
                     "epochs run": len(history["val_loss"]), "best epoch": best,
                     "training loss": history["train_loss"][best - 1], "validation loss": history["val_loss"][best - 1],
                     "validation AP": default_cv["ap"][k]})
    results.table(4, "Early stopping of the network of step 2 on each fold (losses and AP at the restored epoch)",
                  pd.DataFrame(rows))
    results.metrics["default"] = {
        "ap": default_cv["ap"], "auc": default_cv["auc"], "best_epoch": default_cv["best_epoch"],
        "epochs_run": [len(h["val_loss"]) for h in default_cv["histories"]],
        "train_loss_last": [h["train_loss"][-1] for h in default_cv["histories"]],
        "val_loss_last": [h["val_loss"][-1] for h in default_cv["histories"]],
        "val_loss_best": [h["val_loss"][b - 1] for h, b in zip(default_cv["histories"], default_cv["best_epoch"])],
        # the validation AP after the restored epoch: its maximum over the run, the epoch of that maximum, and its last
        # value, to compare what the loss and the ranking say about when to stop
        "val_ap_max": [max(h["val_ap"]) for h in default_cv["histories"]],
        "val_ap_max_epoch": [int(np.argmax(h["val_ap"])) + 1 for h in default_cv["histories"]],
        "val_ap_last": [h["val_ap"][-1] for h in default_cv["histories"]],
    }
    plot_curves(default_cv)

    # --- Step 4: regularization, then the search -------------------------------------------------
    cache = {}

    def cv(config):
        key = (config["lr"], tuple(config["hidden"]), config["weight_decay"], config["dropout"])
        if key not in cache:
            cache[key] = default_cv if config == DEFAULT else cv_network(config, mats)
        return cache[key]

    reg_runs = {name: cv(with_regularization(DEFAULT, name)) for name in REGULARIZATION}
    rows = []
    steps_per_epoch = math.ceil(min(len(fold.y_train) for fold in mats) / BATCH_SIZE)
    for name, run_ in reg_runs.items():
        gap = np.mean([h["val_loss"][b - 1] - h["train_loss"][b - 1]
                       for h, b in zip(run_["histories"], run_["best_epoch"])])
        # AdamW multiplies every weight by (1 - lr * weight_decay) at each step: the factor accumulated by the
        # median restored epoch shows how strongly the decay acted
        decay = (1 - DEFAULT["lr"] * REGULARIZATION[name][0]) ** (steps_per_epoch * np.median(run_["best_epoch"]))
        rows.append({"regularization": name, **summary_row(run_), "validation − training loss": gap,

                     f"({N_FOLDS} validation folds; the loss gap is at the restored epoch)", pd.DataFrame(rows))

               for lr, h, reg in itertools.product(LEARNING_RATES, ARCHITECTURES, REGULARIZATION)]
    rows = []

                     "parameters": MLP(n_inputs, config["hidden"]).n_parameters(), **summary_row(cv(config))})
    # sorted by mean AP; the index keeps each row's position in `configs`
    search = pd.DataFrame(rows).sort_values("AP (mean)", ascending=False, kind="stable")
    search.insert(0, "rank", np.arange(1, len(search) + 1))

    # Selection, on validation only: the differences at the top are within the fold-to-fold noise, so the one-
    # standard-error rule picks the smallest network whose mean AP is within one standard error of the best one
    # (among networks of the same size, the one with the highest mean AP).
    best = search.iloc[0]
    threshold = best["AP (mean)"] - best["AP (sd)"] / np.sqrt(N_FOLDS)
    eligible = search[search["AP (mean)"] >= threshold]
    pick = eligible.sort_values(["parameters", "AP (mean)"], ascending=[True, False], kind="stable").iloc[0]
    search["within one SE"] = np.where(search["AP (mean)"] >= threshold, "yes", "")
    search["chosen"] = np.where(search["rank"] == pick["rank"], "◀", "")
    results.table(6, f"The search: {len(configs)} configurations on the {N_FOLDS} validation folds, sorted by mean "
                     "AP", search, floatfmt={"learning rate": "g"})
    chosen = configs[pick.name]
    chosen_cv = cv(chosen)

    # --- Step 4: the BMI sensitivity check of the EDA, on the chosen configuration ---------------
    low_bmi = cv_network(chosen, fold_matrices(X_train, y_train, folds, make_preprocessor, adult_low_bmi_to_missing))
    n_low_bmi = int(((X_train["age"] >= 18) & (X_train["bmi"] < 12)).sum())
    results.table(7, f"The chosen configuration with the adult BMIs below 12 set to missing ({N_FOLDS} validation "
                     "folds)",

                                {"data": f"the {n_low_bmi} adult BMIs below 12 set to missing",
                                 **summary_row(low_bmi)}]))

    results.metrics.update({
        "n_configs": len(configs), "best_rank1": best.to_dict(), "one_se_threshold": threshold,
        "n_within_one_se": int(len(eligible)), "chosen": chosen, "chosen_rank": int(pick["rank"]),
        "chosen_params": int(pick["parameters"]), "chosen_label": f"{layers(chosen)}, {pick['regularization']}",
        "chosen_cv": {"ap": chosen_cv["ap"], "auc": chosen_cv["auc"], "best_epoch": chosen_cv["best_epoch"]},
        "final_epochs": int(np.median(chosen_cv["best_epoch"])), "low_bmi_ap": low_bmi["ap"], "n_low_bmi": n_low_bmi,
    })
    results.write()
    print(search.head(10).to_string(index=False))
    print(f"chosen: rank {int(pick['rank'])}, {results.metrics['chosen_label']}, lr {chosen['lr']:g}; "
          f"final epochs {results.metrics['final_epochs']}")
    return {"config": chosen, "oof": chosen_cv["oof"], "epochs": results.metrics["final_epochs"]}

def choose_threshold(y, p, cost_miss):
    """The probability threshold (flag when p >= t) with the lowest total cost cost_miss * FN + FP on (y, p).
    Candidates are the observed probabilities and +inf (flag nobody); ties go to the highest threshold."""
    candidates = np.append(np.unique(p), np.inf)
    costs = np.array([cost_miss * np.sum((p < t) & (y == 1)) + np.sum((p >= t) & (y == 0)) for t in candidates])
    best = np.flatnonzero(costs == costs.min()).max()
    return float(candidates[best]), costs, candidates


def decision_metrics(y, p, threshold, cost_miss=COST_MISS):
    """The confusion counts, precision, recall and F1 of both classes, macro F1 and the cost per patient."""
    flag = p >= threshold
    tn, fp = int(np.sum(~flag & (y == 0))), int(np.sum(flag & (y == 0)))
    fn, tp = int(np.sum(~flag & (y == 1))), int(np.sum(flag & (y == 1)))
    precision, recall, f1, _ = precision_recall_fscore_support(y, flag.astype(int), labels=[0, 1], zero_division=0)
    return {"TN": tn, "FP": fp, "FN": fn, "TP": tp, "precision": precision.tolist(), "recall": recall.tolist(),
            "f1": f1.tolist(), "macro_f1": float(np.mean(f1)), "flagged": int(flag.sum()),
            "cost_per_patient": (cost_miss * fn + fp) / len(y)}

def paired_bootstrap(y, network_seeds, baselines):
    """Resample the test rows with replacement, the same rows for every model; on each resample, the AP of the network
    (the seed-42 model and the mean over the seeds) and its gap to each baseline. A resample without a positive has
    no AP and is skipped."""
    rng = np.random.default_rng(SEED)
    one_seed = f"seed {SEED}"
    ap = {one_seed: [], "mean of the seeds": []}
    diffs = {(net, name): [] for net in ap for name in baselines}
    for _ in range(N_BOOTSTRAP):
        idx = rng.integers(0, len(y), len(y))
        if y[idx].sum() == 0:
            continue
        seeds = [average_precision_score(y[idx], p[idx]) for p in network_seeds.values()]
        nets = {one_seed: seeds[list(network_seeds).index(SEED)], "mean of the seeds": float(np.mean(seeds))}
        for net, value in nets.items():
            ap[net].append(value)
            for name, p in baselines.items():
                diffs[(net, name)].append(value - average_precision_score(y[idx], p[idx]))
    return {"n": len(ap[one_seed]),
            "network_ap_ci": {k: np.percentile(v, [2.5, 97.5]).tolist() for k, v in ap.items()},
            "diff": {f"{net} - {name}": {"ci": np.percentile(d, [2.5, 97.5]).tolist(),
                                         "share_positive": float(np.mean(np.array(d) > 0))}
                     for (net, name), d in diffs.items()}}


def mcnemar(y, flag_a, flag_b):
    """Exact McNemar test on the patients the two models classify differently: under the null both kinds of
    disagreement are equally likely, so the count of one kind is Binomial(disagreements, 1/2)."""
    right_a, right_b = flag_a == (y == 1), flag_b == (y == 1)
    only_a, only_b = int(np.sum(right_a & ~right_b)), int(np.sum(~right_a & right_b))
    p = binomtest(only_a, only_a + only_b, 0.5).pvalue if only_a + only_b else 1.0
    return {"only_first_right": only_a, "only_second_right": only_b, "p": float(p)}

    # The same rule for every model. The majority class gives every patient the same score, so its only choices are
    # flagging everyone or no one; the rule picks the cheaper of the two on validation.
    thresholds = {name: choose_threshold(y_train, p, COST_MISS)[0] for name, p in oof.items()}
    rows = []
    for cost in COST_SENSITIVITY:
        t = choose_threshold(y_train, chosen["oof"], cost)[0]
        m = decision_metrics(y_train, chosen["oof"], t, cost)
        rows.append({"cost of a miss": cost, "threshold": t, "recall (1)": m["recall"][1],
                     "precision (1)": m["precision"][1], "flagged (% of patients)": 100 * m["flagged"] / len(y_train),
                     "cost per patient": m["cost_per_patient"]})
    results.table(8, "The chosen network's threshold on the out-of-fold validation probabilities, for three costs "
                     "of a miss", pd.DataFrame(rows),
                  floatfmt={"cost of a miss": "d", "flagged (% of patients)": ".2f"})
    plot_threshold(y_train, chosen["oof"], thresholds["Network"])
    # pos_weight multiplies the odds the network learns by w = negatives / positives; dividing the odds of the threshold
    # by w gives the probability it stands for once that factor is undone, to compare with p* = 1 / (1 + COST_MISS)
    w = (y_train == 0).sum() / (y_train == 1).sum()
    t = thresholds["Network"]
    results.metrics.update({
        "thresholds": {k: (v if np.isfinite(v) else None) for k, v in thresholds.items()}, "pos_weight": float(w),
        "threshold_corrected": t / (t + (1 - t) * w), "p_star": 1 / (1 + COST_MISS),
        "validation_decisions": {name: decision_metrics(y_train, p, thresholds[name]) for name, p in oof.items()},
    })

    # --- Once: the final models on the test rows -------------------------------------------------
    preprocessor = make_preprocessor().fit(X_train)
    X_a, X_b = preprocessor.transform(X_train), preprocessor.transform(X_test)
    seed_models = {seed: train(X_a, y_train, chosen["config"], seed, epochs=chosen["epochs"])[0] for seed in SEEDS}
    seed_probs = {seed: predict_proba(model, X_b) for seed, model in seed_models.items()}
    probabilities = {"Network": seed_probs[SEED]}
    for name, model in make_baselines().items():
        probabilities[name] = model.fit(X_a, y_train).predict_proba(X_b)[:, 1]

    metrics = {}
    for name, p in probabilities.items():
        metrics[name] = decision_metrics(y_test, p, thresholds[name])
        metrics[name].update({"ap": average_precision_score(y_test, p), "auc": roc_auc_score(y_test, p),
                              "threshold": thresholds[name] if np.isfinite(thresholds[name]) else None})
    per_seed = {seed: {**decision_metrics(y_test, p, thresholds["Network"]), "ap": average_precision_score(y_test, p),
                       "auc": roc_auc_score(y_test, p)} for seed, p in seed_probs.items()}

    def mean_over_seeds(key, index=None):
        return float(np.mean([m[key] if index is None else m[key][index] for m in per_seed.values()]))

    labels = {"Network": f"Network (seed {SEED})"}
    rows, per_class = [], []
    for name, m in metrics.items():
        rows.append({"model": labels.get(name, name), "AP": m["ap"], "ROC-AUC": m["auc"],
                     "threshold (validation)": m["threshold"] if m["threshold"] is not None else np.nan,
                     "TN": m["TN"], "FP": m["FP"], "FN": m["FN"], "TP": m["TP"],
                     "cost per patient": m["cost_per_patient"]})
        per_class.append({"model": labels.get(name, name), "precision (0)": m["precision"][0],
                          "recall (0)": m["recall"][0],
                          "F1 (0)": m["f1"][0], "precision (1)": m["precision"][1], "recall (1)": m["recall"][1],
                          "F1 (1)": m["f1"][1], "macro F1": m["macro_f1"]})
        if name == "Network":   # the same row averaged over the seeds, right below the seed-42 one
            rows.append({"model": f"Network (mean of {len(SEEDS)} seeds)", "AP": mean_over_seeds("ap"),
                         "ROC-AUC": mean_over_seeds("auc"), "threshold (validation)": thresholds["Network"],
                         **{k: mean_over_seeds(k) for k in ("TN", "FP", "FN", "TP")},
                         "cost per patient": mean_over_seeds("cost_per_patient")})
            per_class.append({"model": f"Network (mean of {len(SEEDS)} seeds)",
                              **{f"{metric} ({c})": mean_over_seeds(key, c) for c in (0, 1)
                                 for metric, key in (("precision", "precision"), ("recall", "recall"), ("F1", "f1"))},
                              "macro F1": mean_over_seeds("macro_f1")})
    counts = {k: ".1f" for k in ("TN", "FP", "FN", "TP")}   # the seed mean is not a whole number of patients
    # dtype=object keeps each model's whole counts as integers next to the seed means
    results.table(9, "The test set, used once: AP, ROC-AUC and the decisions at each model's validation threshold",
                  pd.DataFrame(rows, dtype=object), floatfmt=counts)
    columns = ["model", "precision (0)", "recall (0)", "F1 (0)", "precision (1)", "recall (1)", "F1 (1)", "macro F1"]
    results.table(10, "Precision, recall and F1 per class on the test set (0 = no stroke, 1 = stroke)",
                  pd.DataFrame(per_class)[columns])

    seeds = pd.DataFrame([{"seed": seed, "AP": m["ap"], "ROC-AUC": m["auc"], "recall (1)": m["recall"][1],
                           "false alarms": m["FP"], "cost per patient": m["cost_per_patient"]}
                          for seed, m in per_seed.items()])
    (ap_mean, ap_sd), (auc_mean, auc_sd) = mean_sd(seeds["AP"]), mean_sd(seeds["ROC-AUC"])
    results.table(11, f"The chosen network retrained with {len(SEEDS)} seeds, on the test set", seeds,
                  floatfmt={"seed": "d"})

    # --- The success criterion of step 0, and how far the numbers can be trusted -----------------
    base_ap = metrics[best_baseline]["ap"]
    gain = ap_mean / base_ap - 1
    met = bool(gain >= CRITERION_GAIN and ap_mean - base_ap > ap_sd)
    bootstrap = paired_bootstrap(y_test, seed_probs, {k: probabilities[k] for k in LEARNED_BASELINES})
    flags = {name: probabilities[name] >= thresholds[name] for name in ("Network", *LEARNED_BASELINES)}
    cost_rows = {"flag nobody": COST_MISS * y_test.sum() / len(y_test),
                 "flag everyone": (y_test == 0).sum() / len(y_test)}
    results.metrics.update({
        "test": metrics, "per_seed": per_seed,
        "seeds": {"ap": seeds["AP"].tolist(), "auc": seeds["ROC-AUC"].tolist(), "ap_mean": ap_mean, "ap_sd": ap_sd,
                  "auc_mean": auc_mean, "auc_sd": auc_sd},
        "best_baseline": best_baseline, "best_baseline_ap": base_ap, "criterion_gain": gain, "criterion_met": met,
        "gain_vs": {k: ap_mean / metrics[k]["ap"] - 1 for k in LEARNED_BASELINES}, "bootstrap": bootstrap,
        "mcnemar": {k: mcnemar(y_test, flags["Network"], flags[k]) for k in LEARNED_BASELINES},
        "trivial_costs": cost_rows, "test_rows": len(y_test), "test_positives": int(y_test.sum()),
        "epochs": chosen["epochs"],
    })
    plot_curves(y_test, probabilities, metrics, labels)
    plot_confusion({labels.get(name, name): metrics[name] for name in ("Network", *LEARNED_BASELINES)})
    results.write()
    print(seeds.to_string(index=False))
    print(f"network AP {ap_mean:.4f} ± {ap_sd:.4f} vs {best_baseline} {base_ap:.4f}: gain {gain:+.2%}, met: {met}")
    print(f"bootstrap: {json.dumps(bootstrap)}")
    print(f"McNemar: {results.metrics['mcnemar']}")
    return {"model": seed_models[SEED], "preprocessor": preprocessor, "probabilities": probabilities,
            "threshold": thresholds["Network"]}

import matplotlib.pyplot as plt

from network import predict_proba

N_REPEATS = 30            # permutations per feature
N_WORST = 5               # worst examples shown of each kind of error
GLUCOSE_VALLEY = 175      # mg/dL: the valley between the two glucose modes found by the EDA
ADULT, OLD = 18, 60       # the EDA's age bands: under 18, 18 to 59, 60 or more


def age_bands(age):
    """The EDA's three age bands, as masks."""
    return {f"under {ADULT}": age < ADULT, f"{ADULT}–{OLD - 1}": (age >= ADULT) & (age < OLD),
            f"{OLD} or more": age >= OLD}


def subgroups(X):
    """Subgroups taken from the EDA's findings — age bands, the clinical flags, BMI missingness, the glucose mode —
    and gender, which the EDA found unrelated to stroke, as a check that the errors do not fall on one group."""
    return {
        **{("age", band): mask for band, mask in age_bands(X["age"]).items()},
        ("hypertension", "no"): X["hypertension"] == 0, ("hypertension", "yes"): X["hypertension"] == 1,
        ("heart disease", "no"): X["heart_disease"] == 0, ("heart disease", "yes"): X["heart_disease"] == 1,
        ("BMI", "recorded"): X["bmi"].notna(), ("BMI", "missing"): X["bmi"].isna(),
        ("glucose", f"below {GLUCOSE_VALLEY}"): X["avg_glucose_level"] < GLUCOSE_VALLEY,
        ("glucose", f"{GLUCOSE_VALLEY} or more"): X["avg_glucose_level"] >= GLUCOSE_VALLEY,
        ("gender", "female"): X["gender"] == "Female", ("gender", "male"): X["gender"] == "Male",
    }


def plot_subgroups(table):

def clinical_flags(X):
    """The three recorded risk markers the EDA found associated with stroke beyond age."""
    return {"hypertension": X["hypertension"] == 1, "heart disease": X["heart_disease"] == 1,
            f"glucose {GLUCOSE_VALLEY} or more": X["avg_glucose_level"] >= GLUCOSE_VALLEY}


def run(X_test, y_test, final):
    """Step 6 (Tables 12-15, Figures 6-7), on the seed-42 network of step 5 at its validation threshold."""
    results = Results("errors")
    p, t = final["probabilities"]["Network"], final["threshold"]
    alarm = p >= t   # the network's decisions: True flags the patient

    rows = []
    for (feature, group), mask in subgroups(X_test).items():
        mask = mask.to_numpy()
        pos, neg = int((y_test[mask] == 1).sum()), int((y_test[mask] == 0).sum())
        fn, fp = int((~alarm & mask & (y_test == 1)).sum()), int((alarm & mask & (y_test == 0)).sum())
        rows.append({"feature": feature, "subgroup": group, "patients": int(mask.sum()), "strokes": pos, "missed": fn,
                     "false alarms": fp, "miss rate (%)": 100 * fn / pos if pos else np.nan,
                     "false-alarm rate (%)": 100 * fp / neg if neg else np.nan,
                     "error rate (%)": 100 * (fn + fp) / mask.sum(),
                     "cost per patient": (COST_MISS * fn + fp) / mask.sum()})
    table = pd.DataFrame(rows)
    results.table(12, "Errors of the network by subgroup on the test set, at the validation threshold", table,
                  floatfmt={"miss rate (%)": ".2f", "false-alarm rate (%)": ".2f", "error rate (%)": ".2f"})
    worst = table.loc[table["error rate (%)"].idxmax()]
    costliest = table.loc[table["cost per patient"].idxmax()]
    plot_subgroups(table)

    # Does the network use the clinical flags, or only age? The share of non-strokes it flags, with and without each
    # flag (and with any of them against none), inside each adult age band, with their median age: within a band the
    # patients who carry a flag are also older, so the comparison is not at equal age.
    age, negatives, rows = X_test["age"].to_numpy(), y_test == 0, []
    bands = age_bands(age)
    markers = {name: has.to_numpy() for name, has in clinical_flags(X_test).items()}
    any_marker = np.any(list(markers.values()), axis=0)
    for band in (f"{ADULT}–{OLD - 1}", f"{OLD} or more"):
        for name, has in {**markers, "any of the three": any_marker}.items():
            with_, without = bands[band] & negatives & has, bands[band] & negatives & ~has
            rows.append({"age": band, "flag": name, "non-strokes with it": int(with_.sum()),
                         "median age with it": np.median(age[with_]), "flagged with it (%)": 100 * alarm[with_].mean(),
                         "non-strokes without it": int(without.sum()), "median age without it": np.median(age[without]),
                         "flagged without it (%)": 100 * alarm[without].mean()})
    results.table(13, "Share of the non-strokes the network flags, with and without each clinical flag, by age band "
                      "(test set)", pd.DataFrame(rows),
                  floatfmt={"median age with it": ".1f", "flagged with it (%)": ".2f", "median age without it": ".1f",
                            "flagged without it (%)": ".2f"})
    strokes_18_59 = bands[f"{ADULT}–{OLD - 1}"] & (y_test == 1)
    old = bands[f"{OLD} or more"]
    hyper = X_test["hypertension"].to_numpy() == 1

    ids = load_raw()["id"]
    shown = ["age", "gender", "hypertension", "heart_disease", "avg_glucose_level", "bmi", "smoking_status"]
    missed = np.flatnonzero(~alarm & (y_test == 1))
    false_alarms = np.flatnonzero(alarm & (y_test == 0))
    picks = [("missed stroke", i) for i in missed[np.argsort(p[missed])][:N_WORST]] + \
            [("false alarm", i) for i in false_alarms[np.argsort(-p[false_alarms])][:N_WORST]]
    examples = pd.DataFrame([{"error": kind, "id": str(ids[X_test.index[i]]), **X_test.iloc[i][shown].to_dict(),
                              "probability": p[i]} for kind, i in picks])
    examples["bmi"] = examples["bmi"].map(lambda v: "missing" if pd.isna(v) else f"{v:.1f}")
    results.table(14, f"The worst errors: the {N_WORST} strokes with the lowest probability and the {N_WORST} "
                      "non-strokes with the highest", examples,
                  floatfmt={"age": "g", "avg_glucose_level": ".2f", "probability": ".4f"})

    model, preprocessor = final["model"], final["preprocessor"]
    base = average_precision_score(y_test, p)
    rng = np.random.default_rng(SEED)
    rows = []
    for feature in FEATURES:
        drops = []
        for _ in range(N_REPEATS):
            X = X_test.copy()
            X[feature] = rng.permutation(X[feature].to_numpy())
            drops.append(base - average_precision_score(y_test, predict_proba(model, preprocessor.transform(X))))
        rows.append({"feature": feature, "AP drop (mean)": np.mean(drops), "AP drop (sd)": np.std(drops, ddof=1)})
    importance = pd.DataFrame(rows).sort_values("AP drop (mean)", ascending=False, kind="stable").reset_index(drop=True)
    results.table(15, f"Permutation importance on the test set ({N_REPEATS} permutations per feature; "
                      f"test AP {base:.4f})", importance)
    plot_importance(importance)

    results.metrics.update({
        "worst_subgroup": f"{worst['feature']}: {worst['subgroup']}",
        "worst_error_rate": float(worst["error rate (%)"]),
        "worst_subgroup_row": worst.to_dict(), "costliest_subgroup_row": costliest.to_dict(),

    7. Conclusion

    Was the network worth it? No. It meets the criterion written before training, against the baseline that validation chose, but that baseline, tied with logistic regression on validation, turned out the weaker of the two on the test set, and the bootstrap interval of even that comparison contains 0. Logistic regression — linear, deterministic, readable coefficient by coefficient — matches the network on validation (0.1891 against 0.2033, inside the fold noise), on the test set (0.2675 against the network's mean of 0.2622), in ROC-AUC (0.8440 against 0.8413 ± 0.0041) and in its decisions (McNemar p = 0.62), at a lower cost per patient (0.4423 against 0.4644 for the network's seed mean; only seed 45, at 0.4413, is marginally below it). On ten recorded features of which age carries most of the signal, the network shows no measurable advantage over a weighted sum of them.

    Limitations.

    • 50 test strokes. The test AP is known to about ±0.1 (95% bootstrap interval [0.1746, 0.3803] for the seed mean), and differences of a few strokes between models are within chance.
    • Optimistic validation numbers. Early stopping and the AP use the same validation fold, and the chosen configuration is selected among 48, so its validation AP flatters it; the test AP is the unbiased number, though a noisy one, and nested cross-validation would measure the gap. On this split the test AP is in fact higher than the validation AP for all three learned models (network 0.2622 against 0.2033, logistic regression 0.2675 against 0.1891, gradient boosting 0.2075 against 0.1966): the final models train on all 4,088 rows instead of about 3,270, and with 50 test strokes the test AP is known only to about ±0.1, so the gap says little about the optimism.
    • An uneven search. The baselines keep their library defaults while the network was chosen among 48 configurations, which favours the network; it still does not beat logistic regression.
    • A label of unknown provenance. The EDA could not establish how or when the data were recorded; the model is a classifier of the recorded label, not a validated predictor of future strokes. The BMI-missing indicator was removed for that reason, at a cost in validation AP.
    • Probabilities that are not risks. pos_weight inflates the odds about 19.5 times. The threshold accounts for it, but the raw outputs must not be read as a patient's probability of a stroke without recalibration.
    • A cost we chose. The 20:1 cost of a miss is our assumption; Table 8 shows how the decisions move under 10:1 and 50:1.

    Who would be affected by an error. Younger patients who do have a stroke: the network misses 10 of the 11 strokes between 18 and 59, 9 of them in patients with none of the three clinical flags, so its silence would wrongly reassure exactly the patients a screening is least likely to catch otherwise. On the other side, almost every patient aged 60 or more is flagged (96.15% of those without a stroke), which spends follow-up consultations and causes worry where most alarms are false.

    Responsible use. As it stands, the network should not be used to make decisions about patients. Used at all, it could only add patients to a follow-up list, never take anyone off one — its silence is least reliable where a stroke is least expected, between 18 and 59 — and the decision would remain a clinician's. Any use would first need a validation on data whose collection timing is known, recalibrated probabilities, and its errors monitored per age band, where they concentrate. The gender check of step 6 finds close error rates (28.55% and 29.55%), but with 50 test strokes a gap between groups cannot be ruled out.

    With more time. More positives — from other datasets or later years of the same source — before any larger model, since 199 strokes limit every estimate here; nested cross-validation to measure what the choices of step 4 cost; recalibration of the probabilities on validation; variables the file lacks, such as when each measurement was taken, medication and the variable behind the second glucose mode; and a comparison with a rule that uses age alone, which this analysis suggests would come close.

    Competition bonus. The dataset is a public Kaggle dataset, not an open competition, so the bonus does not apply.
